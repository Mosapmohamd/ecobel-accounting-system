# Eco Bel — Accounting & Inventory System

Internal dashboard for Eco Bel (skincare/haircare brand): single-warehouse
inventory tracking, B2B wholesale sales with automatic per-customer
discounts and profit tracking, free sample distribution, and finance
entries. Phase 2 of the Eco Bel digital project (after the e-commerce
site, before the social-platform chatbot).

- [`backend/`](./backend) — FastAPI + SQLAlchemy API (see its README for setup)
- [`frontend/`](./frontend) — React + TypeScript + Vite dashboard (see its README for setup)

Both are versioned together here since they ship as one product and are
always deployed in lockstep.
